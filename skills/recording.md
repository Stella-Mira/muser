# 帮用户录人声：从准备到成品

用户说"帮我录一下这首歌的人声"时的完整流程。来自《月亮升起来了》（`samples/v0.4/moon-rising`）的实际录制：
用户分 5 段录了 10 遍，agent 选遍、对齐、混音、做结尾、导出。

## 1. 准备工程

- **在用户自己的工程目录里录**，不要在 muser 仓库的 `samples/` 里录：录音会写进工程旁边的 `recordings/`。
  示例曲先复制一份到用户的工作目录。
- **写歌词**：工程的 `lyrics` 写原文（`"[A] 月亮升起来了，风吹过山冈\n[B] ……"`，`[A]` 这类段落标记会被忽略）。
  view 底部会按卡拉 OK 显示，一句一行，逐字高亮。
- **要有一条"引导旋律"轨**：音符带 `lyric`（ABC 的 `w:` 行）的 `choir.solo`。卡拉 OK 的时间来自它，
  事后检查用户唱得准不准也拿它对照。用户的人声录好以后把它 `muted: true`，别删。
  汉字一字对一个音节，字数和音节数要一样（多出来的标题行、"（哼）"这类要么删掉，要么写成实际唱的字）。

## 2. 开 view，告诉用户怎么录

`muser view <工程> --open`，**不加 `--device`**（录音用浏览器播放）。用大白话告诉用户：

1. 戴耳机（伴奏不漏进麦克风）。
2. 在时间尺上右键拖出要录的那段（一句或一段），点「● 录循环区间」；有 1 小节预备拍。起点尽量拖准到小节线。
3. 一段可以录很多遍，新的一遍自动替换同一位置的旧片段，旧的都留在右边的列表里（「用这一遍」/「删除」）。
4. 不满意的地方可以：✂（或按 C）在换气处剪开；拖动片段挪位置；点一下选中，← → 每次 10 毫秒微调。
5. 满意了点「保存」，工程 JSON 才会变。

把段落和小节号列成表给用户（第几小节到第几小节唱哪句）。

## 3. 录完：看每一遍

`muser takes <工程>`：每一遍的起点、长度、平均电平、实际唱的部分、工程用了没有。

## 4. 对齐

- **整体延迟**：把录音的音高曲线（逐帧基频）和引导旋律的音高比对，在 −400 到 +600 毫秒之间找最吻合的时间差。
  平均误差在 1 个半音以内说明对上了（唱低一个八度没关系，比的是相对音高）。
  - 每一遍都晚差不多一样多 → 录音延迟：让用户在「延迟微调」里填这个毫秒数再录（这次是约 70 毫秒）。
  - 有早有晚 → 是唱的起伏，不用补。
  - 要分清两者，让用户拍手录 16 下（拍手比唱准）。
- **某一句拖了**：逐句（按歌词的句子、用引导旋律的音符起止）量时间差，超过 +50 毫秒的才动。
  在这句前面的换气处剪开（音频片段的 `offset` / `start` / `length`），后半段提前；前半段的末尾相应缩短，
  **不要重叠**（重叠会听到两遍）；接缝各加 30 毫秒 `fade_in` / `fade_out`。挪完再量一次。
  量出来的时间差会有几十毫秒的误差，两次测量出入大时取中间值，并告诉用户改了哪几句、各多少毫秒。

## 5. 混音

家用麦克风录的人声一般很小（平均 −27 到 −30 dB）、很干。起点：

| 位置 | 设置 |
|---|---|
| 人声轨效果链 | 高通 90 Hz → 300 Hz −2.5 dB（去闷）→ 压缩 −32 dB、3:1、补偿 +6 dB → 3 kHz +2 dB（吐字）→ 8 kHz 高架 +2.5 dB（空气感） |
| 人声专用混响总线 | 高通 300 Hz、低通 9 kHz、混响 2 秒；发送约 −13 dB（−7 用户嫌太湿） |
| 回声总线 | 一个八分音符的延迟、反馈 0.3、高低频切掉，再送进人声混响；发送约 −15 dB |
| 乐器的混响 | 人声也送一点（约 −18 dB），和伴奏在同一个空间 |
| 推子 | 用 `mix-report` 调到比最响的乐器高 1–2 LU |

## 6. 氛围与结尾

- **氛围声（风、雨、环境）要很轻**：比人声低约 30 LU，切掉高低频（如风声只留 200–1400 Hz）。
  第一次只低了 14 LU，用户说"这是狂风"。
- **别戛然而止**：加一个结尾段（2–3 小节、主和弦）。吉他从低到高依次拨响（每根弦晚约 0.09 拍、越往上越轻），
  贝斯托底，铺底的弦乐、合唱在最后半段用 `gain_db` 自动化淡出；渲染时 `--tail 3` 留出余音。

## 7. 交付

- 改之前把工程备份一份（`<名字>.before-mix.json` 之类），告诉用户。
- MP3：`muser render` 出 WAV，再 `ffmpeg -i x.wav -codec:a libmp3lame -b:a 320k x.mp3`。
- 要"合成哼唱版"对比：另存一份临时工程（引导旋律取消静音、人声轨静音；`recordings/` 的路径改成绝对路径），渲染导出。
- 用户的工程只在用户同意的改动上写回；临时工程放在别处。
